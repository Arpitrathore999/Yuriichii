# Elara Bot

Modular Telegram AI companion.

## Features
- AI companion chat
- `/ai <message>`
- DM natural chat
- Group trigger: `Elara hello`
- Bot mention trigger
- Reply-to-Elara trigger
- MongoDB conversation history
- Groq AI
- Social commands:
  hug, kiss, bite, slap, kick, cuddle, pat, highfive,
  flirt, love, crush, couple, propose, marriage, divorce

## Setup
1. Copy `.env.example` to `.env`
2. Fill Telegram API credentials, bot token, MongoDB URI and Groq key.
3. Install dependencies:
   `pip install -r requirements.txt`
4. Run:
   `python main.py`
